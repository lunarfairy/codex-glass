# Codex Glass v1.0.3

新增五小时额度可视化：浮窗最上方是 2 像素高的绿色十段条，每段约代表 10% 剩余额度；下方蓝色条与数字继续显示本周额度。保留浅色透明胶囊、置顶拖动和悬停倒计时。

## 下载与安装

1. 下载本页 Assets 中的 **CodexGlass-v1.0.3-windows-x64.zip**，不要下载 Source code。
2. 按 [官方说明](https://github.com/openai/codex#quickstart) 自行安装 Codex CLI；运行 `codex --version` 确认可用，再运行 `codex` 使用 ChatGPT 账户登录。
3. 全部解压 ZIP，双击 **安装.cmd**。适用于 Windows 10/11 x64，无需管理员权限或另装 .NET。
4. 安装完成自动打开控制面板；打开已登录的 Codex 桌面端后显示浮窗。

已安装旧版可直接运行新安装器升级。桌面 **Codex Glass** 图标可打开控制面板，调整悬浮条和开机自启。升级会重新启用开机自启，可以在面板中关闭。

本工具不会主动下载 Codex CLI。仅 API Key 登录或账户未返回相应额度时，无法显示套餐额度。

卸载运行 **卸载.cmd**，不会卸载你自行安装的 CLI 或 Codex 桌面端。安装包附有 README、中文使用说明与 MIT 许可证；SHA256 校验文件随 Release 提供。

更多安装与排错说明见 [README](https://github.com/lunarfairy/codex-glass#安装)。
