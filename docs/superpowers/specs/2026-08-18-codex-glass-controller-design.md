# Codex Glass 控制面板设计

## 目标

提供一个桌面入口。用户双击“Codex Glass 控制台”后，可在小面板中控制悬浮条显示状态和 Windows 开机自启状态。

## 交互

- 桌面图标使用 `--control` 参数启动既有的 Codex Glass 程序。
- 控制面板显示两个明确的开关：`悬浮条` 和 `开机自启`。
- 悬浮条关闭时，额度读取和悬浮窗口都停止；重新开启时恢复既有行为。
- 面板关闭仅关闭面板本身，不改变悬浮条的状态。
- 开机自启开关复用现有注册表启动项；关闭时移除该启动项。

## 架构

控制面板和悬浮条属于同一个可执行程序：首次由桌面图标启动时显示控制面板；常规自动启动时仅按当前配置运行悬浮条。运行中的实例通过本地单实例命令通道接收 `--control`、显示/隐藏和状态查询命令，因此不会产生第二个常驻进程。

设置文件扩展一个 `IsOverlayEnabled` 布尔值，默认开启。现有窗口位置保持不变。额度读取、Codex 桌面端检测和 UI 样式不改变。

## 出错与验证

- 无法写入开机启动项时，面板显示失败状态，并保留原开关状态。
- 控制命令无法连接到运行实例时，桌面入口启动一个新的控制面板实例。
- 单元测试覆盖默认开关、关闭后不显示悬浮窗、注册/移除开机启动项的状态转换，以及命令解析。
- 手动验证桌面图标、两枚开关以及关闭面板后的悬浮条状态。
