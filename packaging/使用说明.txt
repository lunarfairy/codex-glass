Codex Glass
===========

安装前请先按 https://github.com/openai/codex#quickstart 安装官方 Codex CLI。
在终端执行 codex --version 确认 CLI 可用，再双击“安装.cmd”。不需要管理员权限。
在终端运行 codex，按提示用 ChatGPT 账户登录，并打开已登录的 Codex 桌面端。
ZIP 必须“全部解压缩”后运行，不能只复制 app 中的 EXE。
安装完成会直接打开控制面板；以后双击桌面“Codex Glass”可开关浮窗和开机自启。
更新：解压新版本，直接运行“安装.cmd”，保留浮窗设置，重新启用开机自启。
卸载：双击“卸载.cmd”；不会删除你自行安装的 Codex CLI、桌面端或账户配置。

使用方式：
- 先登录 Codex 桌面端；Codex 打开时，右上角会出现浅色玻璃悬浮条。
- 顶部绿色十段条显示五小时剩余额度，每段约 10%，四舍五入。
- 中间百分比与底部蓝色线显示本周剩余额度。
- 鼠标移入后会展开并显示重置倒计时。
- 按住悬浮条可拖动，位置会自动记住。
- Codex 关闭后悬浮条会隐藏；下次打开 Codex 时自动出现。
- 应用随 Windows 在后台启动，不会出现在任务栏。
- 安装包不会下载或内置 Codex CLI，安装器会检查已安装的官方 CLI。

遇到“—”或无法读取额度时，先确认终端中的 codex 已登录并可联网。
安装包适用于 Windows 10/11 x64，自带 .NET 运行时。
详细安装和排错步骤见同目录 README.md。
新版下载：https://github.com/lunarfairy/codex-glass/releases/latest

隐私：
- 只读取 Codex 本机官方额度接口。
- 不读取提示词、代码或对话内容。
- 不开启网络监听端口。
